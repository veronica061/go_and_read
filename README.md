# Книжный уголок

**Веб-приложение для онлайн-продажи книг с возможностью чтения**

## Описание проекта

«Книжный уголок» — это интернет-магазин книг на Django, позволяющий пользователям просматривать каталог, добавлять книги в корзину, оформлять заказы и читать книги онлайн. Проект включает панель администратора для управления контентом.

## Функциональные возможности

### Для пользователей:
-  Просмотр каталога книг с фильтрацией по жанрам
-  Поиск книг по названию и автору
-  Регистрация и авторизация
-  Добавление книг в корзину, изменение количества, удаление
-  Оформление заказа с выбором способа оплаты
-  Онлайн-чтение книг (заглушка)
-  Адаптивный дизайн

### Для администраторов (через Django Admin):
- Управление книгами, авторами, жанрами
- Управление заказами (просмотр, изменение статуса)
- Управление пользователями

## Технологический стек

- **Backend:** Django
- **Database:** SQLite (для разработки)
- **Frontend:** HTML, CSS, JavaScript, Bootstrap 5
- **Аутентификация:** Django Auth
- **API:** Django для AJAX-запросов

## Модели данных

### Book (Книга)
- Название, автор, жанр
- Описание, цена, обложка
- Флаг доступности

### Author (Автор)
- Имя автора

### Genre (Жанр)
- Название жанра

### Cart (Корзина)
- Привязка к пользователю
- Элементы корзины

### Order (Заказ)
- Данные пользователя
- Статус заказа (ожидает, в обработке, доставлен)
- Способ оплаты

## Установка и запуск (разработка)

### 1. Клонирование репозитория
```bash
git clone <url-репозитория>
cd book_corner
```

### 2. Создание виртуального окружения
```bash
# Для Windows
python -m venv venv
venv\Scripts\activate

# Для Linux/macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка базы данных
```bash
# Применение миграций
python manage.py migrate

# Создание суперпользователя (администратора)
python manage.py createsuperuser
# Следуйте инструкциям в терминале
```

### 6. Запуск сервера разработки
```bash
python manage.py runserver
```

### 7. Доступ к приложению
- Основное приложение: [http://127.0.0.1:8000](http://127.0.0.1:8000)
- Панель администратора: [http://127.0.0.1:8000/admin](http://127.0.0.1:8000/admin)

## Использование

### Для пользователя:
1. **Регистрация/Вход**: Нажмите кнопку "Регистрация" или "Войти" в правом верхнем углу
2. **Просмотр каталога**: Перейдите в раздел "Каталог"
3. **Добавление в корзину**: Нажмите "В корзину" на странице книги
4. **Оформление заказа**: Перейдите в корзину и нажмите "Оформить заказ"
5. **Чтение**: Нажмите "Читать" на странице любой книги

### Для администратора:
1. **Вход в админку**: Перейдите по адресу `/admin`
2. **Управление контентом**: Используйте разделы "Книги", "Авторы", "Жанры"
3. **Управление заказами**: Раздел "Заказы" для изменения статусов

## Развертывание в продакшн
