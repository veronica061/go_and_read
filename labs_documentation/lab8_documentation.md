## **Документ 3: Руководство системного программиста (РСП)**

**Наименование документа:** РУКОВОДСТВО СИСТЕМНОГО ПРОГРАММИСТА программного средства «Книжный уголок» (для тестового развертывания).

**Обозначение:** РСП-КУ.
**Версия:** 1.0
**Дата составления:** 15.12.2025

### **1. Введение**

#### 1.1. Назначение документа
Руководство предназначено для развертывания и администрирования веб-приложения «Книжный уголок» в тестовой конфигурации.

#### 1.2. Краткое описание системы
Веб-приложение для онлайн-продажи книг на Django с SQLite.

### **2. Требования к окружению**

#### 2.1. Системные требования
- ОС: Windows 10/11, Ubuntu 18.04+, macOS 10.15+
- Python: 3.8 или выше
- ОЗУ: 4 ГБ
- Диск: 1 ГБ свободного места

### **3. Установка и настройка**

#### 3.1. Получение исходного кода
```bash
git clone https://github.com/veronica061/go_and_read.git
cd go_and_read
```

#### 3.2. Настройка виртуального окружения
```bash
# Для Windows
python -m venv venv
venv\Scripts\activate

# Для Linux/macOS
python3 -m venv venv
source venv/bin/activate
```

#### 3.3. Установка зависимостей
```bash
pip install -r requirements.txt
```

#### 3.4. Настройка базы данных
```bash
python manage.py migrate
python manage.py createsuperuser
# Следовать инструкциям для создания администратора
```

#### 3.5. Загрузка тестовых данных
```bash
python manage.py loaddata fixtures/initial_data.json
```

### **4. Запуск системы**

#### 4.1. Запуск сервера
```bash
python manage.py runserver
```

#### 4.2. Проверка работоспособности
1. Открыть браузер
2. Перейти по адресу: `http://127.0.0.1:8000/`

#### 4.3. Тестовые учетные записи
- **Администратор:** создается командой `createsuperuser`
- **Пользователь:** можно зарегистрировать через форму

### **5. Администрирование**

#### 5.1. Панель администратора
- URL: `http://127.0.0.1:8000/admin/`
- Доступ: только для суперпользователя

#### 5.2. Управление контентом
- Разделы: Книги, Авторы, Жанры, Заказы
- Операции: добавление, редактирование, удаление

#### 5.3. Управление базой данных
- Файл: `db.sqlite3` в корне проекта
- Резервное копирование: копирование файла `db.sqlite3`

### **6. Устранение неисправностей**

#### 6.1. Частые проблемы
1. **Ошибка порта:** `python manage.py runserver 8080`
2. **Ошибка зависимостей:** `pip install -r requirements.txt`
3. **Ошибка миграций:** `python manage.py migrate`

#### 6.2. Диагностика
```bash
# Проверка настроек
python manage.py check

# Проверка миграций
python manage.py showmigrations
```

### **7. Остановка системы**
В терминале с запущенным сервером нажать **Ctrl+C**.
