## 4. РАСЧЕТ ФАКТОРА ВЫРАВНИВАНИЯ (VAF)

**Оценка общих характеристик системы (GSC)**

| № | Характеристика | Влияние (0-5) | Обоснование |
|---|----------------|---------------|-------------|
| 1 | Резервное копирование данных | 3 | Данные пользователей и заказов требуют сохранности |
| 2 | Обмен данными | 2 | Интеграция с внешней платежной системой |
| 3 | Распределенные вычисления | 0 | Централизованная архитектура |
| 4 | Важность производительности | 3 | Влияет на пользовательский опыт |
| 5 | Загруженное оборудование | 1 | Стандартные требования к хостингу |
| 6 | Оперативный ввод данных | 3 | Онлайн-оформление заказов |
| 7 | Много форм для ввода | 2 | Умеренное количество форм (5+) |
| 8 | Оперативное обновление БД | 3 | Real-time обновление корзины, заказов |
| 9 | Сложность ввода/вывода | 2 | Средняя сложность операций |
| 10 | Сложность вычислений | 1 | Стандартные бизнес-расчеты |
| 11 | Повторное использование кода | 2 | Компоненты могут переиспользоваться |
| 12 | Преобразование данных | 1 | Стандартная миграция БД |
| 13 | Много установок | 0 | Одиночная инсталляция |
| 14 | Удобство использования | 3 | Важен UI/UX для клиентов |

**ΣGSC** = 3 + 2 + 0 + 3 + 1 + 3 + 2 + 3 + 2 + 1 + 2 + 1 + 0 + 3 = 26

**Расчет VAF**  
**Формула:** VAF = 0.65 + (0.01 × ΣGSC)  
**Расчет:** VAF = 0.65 + (0.01 × 26) = 0.65 + 0.26 = 0.91

## 5. РАСЧЕТ ВЫРОВНЕННЫХ ФУНКЦИОНАЛЬНЫХ ТОЧЕК (AFP)

**Формула:** AFP = UFP × VAF  
**Расчет:** AFP = 156 × 0.91 = 115.57 ≈ 142 FP
